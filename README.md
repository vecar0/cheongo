# 천고 (天鼓)

장단에 맞춰 베고 달리는 수묵화 로그라이크 파쿠르. 휴대폰 가로 화면용 웹앱입니다.

**플레이:** https://vecar0.github.io/akane/

## 부스판 (지금 기본)
동아리 부스에서 처음 하는 사람이 **마우스·키보드로 3~4분 안에 한 판**을 끝내는 판입니다.
- 흐름: 타이틀 → 관문 1 → 갈래 카드(1·2단) → 관문 2 → 오의 카드(3·4단 + 오의) → 천고대 우두머리 → 점수·등급 → 이름 세 글자 → 오늘의 순위
- 조작: A D 이동 · Space 점프 · **왼클릭 베기(커서 쪽)** · **오른클릭 대시 — 누르고 있으면 무아경, 커서로 겨누고 놓으면 일섬** · E 연 · Q 천고난무 · Esc 멈춤
- 쉽게: 난이도 수월 고정, 숨 6, 한 번 쓰러지면 그 관문을 숨 4로 다시, 출구는 적 절반만 베면 열림, 우두머리 체력 0.6배, 천고 기운 1.6배, 플레이 시간 3분 30초 제한
- 거점·상점·영물·해금·저장은 쓰지 않습니다. 손을 떼고 1분(메뉴는 45초)이 지나면 타이틀로 돌아갑니다. 순위는 그 PC 브라우저에만 날짜별로 남습니다.
- 원래의 긴 판: 주소 뒤에 `?full`을 붙이면 엽니다. 부스판 이전 상태 전체는 `backup/web-full-2026-10-23` 브랜치에 그대로 있습니다.
- 수치는 `js/game.js` 맨 위 `BOOTH_CFG`에서 바꿉니다.

## 휴대폰에 설치
- **Android (Chrome):** 메뉴의 "앱으로 설치" 버튼, 또는 Chrome 메뉴 → 홈 화면에 추가
- **iPhone (Safari):** 공유 버튼 → 홈 화면에 추가

한 번 열고 나면 오프라인에서도 실행됩니다. 장단이 곧 규칙이라 소리를 켜고 하세요 (iPhone은 무음 모드를 끄세요).

## 조작
| 터치 | 키보드 | 동작 |
|---|---|---|
| 왼쪽 화면 끌기 | ← → (↑ ↓ 조준) | 이동, 조준 |
| 오른쪽 화면 긋기 / 탭 | J | 그은 방향으로 베기, 길고 빠르게 그으면 돌진베기 |
| 점프 | Space | 점프, 벽에 붙어 있으면 벽차기 |
| 대시 | K | 짧게 누르면 돌진, 길게 누르면 무아경(시간이 느려짐) → 떼면 조준한 방향으로 일섬. 총은 짧게 = 허리 사격, 길게 = 걸으며 조준 |
| 연 | L | 가까운 연을 잡고 날아오르기 |

북이 울리는 박에 맞춰 베면 **일격**이 됩니다. 범위가 넓어지고, 등패수는 일격으로만 쓰러집니다.

휴대폰은 가로·세로 모두 됩니다. 세로로 들면 무대는 위, 버튼은 아래에 놓입니다.

## 구조
- `index.html`, `style.css`: 화면과 오버레이
- `js/content.js`: 게임 내용 데이터 (비급, 무기와 수련 트리, 심법·서약·징조, 오의, 관문 이름)
- `js/tuning.js`: 밸런스 수치 한곳 (이동·숨·적 체력·보스·기세·보상·영물)
- `js/data.js`: 수련터 맵과 판을 이루는 구간 조각
- `js/music.js`: 장단 엔진 (장구·북·징 합성, 박자 시계)
- `js/game.js`: 게임 본체
- `sw.js`, `manifest.webmanifest`: 설치형 웹앱
- `.github/workflows/pages.yml`: master에 푸시하면 GitHub Pages로 배포
