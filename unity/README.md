# 천고 — Unity 프로젝트 (PC)

웹 버전(저장소 루트의 `index.html`, `js/`)을 Unity로 옮긴 것입니다. 앞으로의 개발은 이 폴더에서 합니다.

## 여는 법
1. **Unity Hub**에서 **Unity 6 (6000.x)**을 설치합니다.
2. Unity Hub → **Add → Add project from disk** → 이 `unity` 폴더를 고릅니다.
3. `Assets/Cheongo/Main.unity` 씬(빈 씬이어도 됩니다)에서 **Play**를 누르면 타이틀이 뜹니다.
   씬에 아무것도 둘 필요 없이 코드가 카메라·지형·주인공·메뉴를 만듭니다(`GameRoot.Boot`).
4. 실행 파일은 **File → Build Profiles → Windows → Build**로 만듭니다(씬은 이미 등록돼 있습니다).

## 조작
| 동작 | 키보드 · 마우스 | 게임패드 |
|---|---|---|
| 이동 | ← → / A D | 왼쪽 스틱 |
| 점프 (짧게 누르면 낮게 · 벽에서 벽차기) | Space / Z | A |
| 베기 | J / X / **마우스 왼쪽**(커서 쪽으로) | X |
| 대시 · 무아경 | K / C / Shift / **마우스 오른쪽** | B / RB |
| 천고난무 (북이 다 찼을 때) | Q | Y |
| 발판 아래로 | ↓ + 점프 | |
| 멈춤 · 전체 화면 | Esc · F11 | Start |

- 대시 버튼을 **짧게** 누르면 그냥 대시, **누르고 있으면 무아경**(세상이 느려지고 조준선이 나옵니다), 놓으면 그쪽으로 **일섬**.
  마우스 오른쪽이면 커서 쪽을, 키보드·패드면 방향키 쪽을 겨눕니다.
- 적의 고리가 닫히는 순간 베면 **간파**. 번뜩이는 적 쪽으로 대시하면 멀리서도 붙어 벱니다(간파 돌진).
- 메뉴는 방향키·Enter, 마우스, 패드 어느 것으로든 고릅니다.

## 한 판의 흐름
타이틀 → 관문 다섯(넘을 때마다 **비급** 셋 중 하나, 다음 **길**: 관문 · 험로 · 쉼터 · 수련) → **천고대**(우두머리를 쓰러뜨리고 북을 벤다)
→ 수련 → 다음 바퀴(더 험하게: 정예, 무당·저승사자, 다음 우두머리). 숨이 다하면 끝나고, 얻은 **혼**은 사당에서 다음 길을 위해 씁니다.
관문에 들어설 때마다 저장되어 타이틀의 "이어 가기"로 이어집니다.

## 구조
```
Assets/Cheongo/
  Resources/Data/      웹 게임에서 뽑은 데이터(json): 수치(tuning), 콘텐츠(content), 스킬 트리(tree), 지형 조각(chunks), 표(game)
  Resources/Sprites/   그림(png)과 프레임 좌표(json) — 웹의 모든 시트
  Scripts/Core/        데이터 읽기(GameData), 스프라이트 시트(Sheet), 장단·효과음 합성(Music — 웹의 music.js)
  Scripts/World/       좌표·충돌·지형 생성(World), 지형 그리기(LevelView)
  Scripts/Player/      주인공 몸(Player — 웹의 stepPlayer), 그림(PlayerView: 자세·베기 초승달·날 눈금·무아경 조준선)
  Scripts/Game/
    Sim.cs             전투 규칙: 베기·간파·무아경/일섬·숨·낙법·탄·기력·기세·천고 기운
    Sim.Foes.cs        적 9종
    Sim.Boss.cs        우두머리 10종, 천고난무, 과녁·등불·북
    Run.cs             한 판(Run)과 남는 기록·설정(Meta), 비급·수련 데이터(Content)
    GameRoot.cs        판 진행, 입력(키보드·마우스·패드), 메뉴와 HUD
    FightView.cs / Fx.cs   적·탄·간파 고리·경고 그리기 / 이펙트
  Editor/              그림 가져오기 설정(크기 보존, 압축 없음)
Tests~/                Unity 없이 이동 물리를 시험하는 스크립트 (Unity는 ~ 붙은 폴더를 무시)
```
- 게임 안 좌표는 웹과 같습니다: **픽셀 단위, 32px = 1칸, 아래가 +y**. 그릴 때만 Unity 좌표(1칸 = 1유닛, 위가 +y)로 바꿉니다. 그래서 웹 코드의 수치를 그대로 옮길 수 있습니다.
- 전투의 시간은 모두 노래 위치(`Music.Pos`, 초)로 잽니다. 적의 공격은 박에 맞춰 예약되고(`swingAt`, `fireAt`, 우두머리는 `hitAt`), 그 직전 `FLASH_BASE`초가 간파 창입니다.
- 화면 없이 전투를 시험하려면 `new Sim(level, run, null, null)`로 만들어 `Frame(dt, input)`을 돌리면 됩니다(이펙트·소리 없이 같은 규칙).
- 글꼴은 파일을 넣지 않고 윈도우에 있는 **궁서**(제목·붓글씨)와 **바탕**(본문)을 불러 씁니다(`GameRoot.OnGUI`). 없는 PC에서는 맑은 고딕으로 넘어갑니다.
- 수치를 바꿀 때는 웹과 마찬가지로 `js/tuning.js`를 고친 뒤 아래 변환을 다시 돌립니다(또는 `Resources/Data/tuning.json`을 직접 고칩니다).

## 데이터·그림 다시 뽑기
저장소 루트에서:
```
node tools/unity-export/export.js --all
```
(webp → png 변환에 python3 + Pillow가 필요합니다.)
