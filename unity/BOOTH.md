# 천고 부스판 (동아리 부스용)

지나가는 사람이 **5분 안팎에 처음부터 끝까지 한 판**을 하고, 오늘의 순위에 이름 세 글자를 남기고 가는 판입니다.
웹 버전의 그림·데이터를 그대로 쓰고(`node tools/unity-export/export.js --all`), 흐름만 짧게 바꿨습니다. 코드는 `Assets/Cheongo/Scripts/Game/GameRoot.Booth.cs`.

## 켜는 법
- 실행 파일에 **`-booth`** 를 붙여 실행합니다. 바로가기 대상 예: `천고.exe -booth`
- 또는 타이틀에서 **F9** (부스 모드 켜기/끄기 — 다음 실행에도 유지).
- 부스에서는 **게임패드**를 권합니다(엑스박스 배치: A 점프 · X 베기 · B/RB 대시·무아경 · Y 천고난무 · Start 멈춤). 키보드도 그대로 됩니다.
- 끝내기: 부스 타이틀에는 끝내기 메뉴가 없습니다. 스태프는 **F9로 부스 모드를 끈 뒤** 일반 타이틀의 "끝내기", 또는 Alt+F4.

## 한 판의 흐름
| 순서 | 내용 |
|---|---|
| 타이틀 | 오늘의 순위 1~3위, "시작하기"에서 **아무 버튼**이나 누르면 시작 · "조작 보기" |
| 관문 1 | 첫 관문 동안 화면 아래에 조작 안내(이동·점프·베기·대시/무아경, 간파) |
| 관문 1 → 2 → 3 | 마당이 매번 다릅니다. 관문을 넘을 때마다 숨 +1, 1·2번째 뒤에는 **비급 3장 중 1장** |
| 천고대 앞 | **오의 3장 중 1장** — 고른 갈래의 1·2단과 오의를 함께 익혀, 누구나 오의(천고난무)를 한 번 보게 |
| 천고대 | 우두머리 1명. 베면 끝 |
| 결과 | 점수·등급(甲乙丙丁) → 이름 세 글자(↑↓ 글자, ←→ 칸, Enter) → 오늘의 순위 → 20초 뒤 타이틀 |

- 난이도는 **수월**, 숨 **5**로 시작합니다.
- **한 번 부활**: 숨이 다하면 그 관문을 숨 3으로 처음부터 다시. 두 번째는 결과 화면.
- **제한 시간 7분**: 넘으면 "시간이 다 됐다"로 결과. 남은 시간은 오른쪽 위에 표시(1분 남으면 붉게).
- **자리 비움**: 싸우는 중 60초, 메뉴·이름 입력 중 45~60초 동안 손을 대지 않으면 타이틀로 돌아갑니다.
- 이어 가기 저장은 하지 않습니다(다음 사람이 이어 받지 않게).

## 점수
`벤 적×10 + 간파×25 + 완벽 간파×40 + 넘은 관문×120(천고대 도달 300) + 우두머리를 베면 1000 + 남은 시간(초)×3`
등급: 甲 2600 이상 · 乙 1700 · 丙 900 · 丁 그 아래. 순위는 이 PC에만(PlayerPrefs) 날짜별로 남습니다.

## 바꾸고 싶을 때
`GameRoot.Booth.cs` 맨 위 `Booth` 상수: 관문 수 `GATES`, 제한 시간 `LIMIT`, 자리 비움 `IDLE_*`, 시작 숨·부활 숨, 난이도 `DIFF`.

## 이번에 웹에서 함께 넘어온 것
- 주인공 달리기(`mvrun`, 8프레임)와 우두머리 7종 걷기(`bwalk`, 4프레임씩)를 **양발이 번갈아 나가도록 다시 그린 그림** — Unity의 `PlayerView`·`FightView`도 웹과 같은 규칙으로 이 그림을 씁니다.
- 마당 소품(`md0~4`), 깃대·상자·등(`mapobj`), 한지 패(`ui-plate`) 등 최근 그림과 수치·콘텐츠 데이터.

## 확인한 것 / 직접 봐야 할 것
- 클라우드에서 Unity 에디터 없이 **C# 컴파일 검사**(Roslyn, UnityEngine 참조 어셈블리)로 오류 0을 확인했습니다.
- 화면에서 직접 확인이 필요한 것: 부스 타이틀·결과·이름 입력 화면 배치, 첫 관문 조작 안내 위치, 새 달리기·걷기 그림의 크기와 발 위치, 패드 버튼 배치.
