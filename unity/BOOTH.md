# 천고 부스판 (동아리 부스용)

지나가는 사람이 **3분 안팎에 한 판**을 끝까지 하고, 오늘의 순위에 이름 세 글자를 남기고 가는 판입니다.
**Unity 빌드는 이제 부스판이 기본**입니다(해금·사당·이어 가기 같은 바깥 요소 없음).
코드는 `Assets/Cheongo/Scripts/Game/GameRoot.Booth.cs`, 땅은 `Sim.Terrain.cs`·`World/TerrainView.cs`.

## 켜고 끄기
- 그냥 실행하면 부스판입니다. 예전의 긴 판(사당·무기 해금 등)은 `천고.exe -full` 또는 타이틀에서 **F9**.
- 게임패드를 권합니다(엑스박스 배치: A 점프 · X 베기 · B/RB 대시·무아경 · Y 천고난무 · Start 멈춤). 키보드도 됩니다.
- 스태프 종료: F9로 긴 판으로 바꾼 뒤 "끝내기", 또는 Alt+F4.

## 한 판의 흐름 (약 3분)
| 순서 | 내용 |
|---|---|
| 타이틀 | 오늘의 순위 1~3위 · "시작하기"에서 아무 버튼 |
| 관문 1 | 웹과 같은 땅(웹 생성기로 만든 짧은 관문, 조각 3개). 마당은 판마다 다르게 둘 |
| 관문 1 → 2 | 비급 카드 3장 중 1장(웹과 같은 그림 아이콘) |
| 천고대 앞 | 오의 카드 3장 중 1장 — 고른 갈래의 1·2단과 오의를 함께 익힘 |
| 천고대 | 우두머리 1명(체력 0.6배). 베면 끝 |
| 결과 | 점수·등급 → 이름 세 글자 → 오늘의 순위 → 20초 뒤 타이틀 |

## 쉽게 · 짧게 한 것
| 항목 | 웹 / 긴 판 | 부스판 |
|---|---|---|
| 관문 | 다섯 + 천고대 | **둘 + 천고대** |
| 관문 길이 | 조각 5개 | **조각 3개** |
| 난이도 | 보통 | **수월** |
| 시작 숨 | 4 | **6** (관문마다 +1, 상자에서 +1) |
| 부활 | 없음 | 한 번 — 그 관문을 숨 4로 처음부터 |
| 출구 결계 | 적 6할을 베어야 열림 | **5할** |
| 우두머리 체력 | 1배 | **0.6배** |
| 천고 기운 | 1배 | **1.6배** (누구나 천고난무를 써 보게) |
| 제한 시간 | — | **5분** |

## 웹에서 함께 넘어온 것
- **땅**: 웹 생성기가 만든 관문을 그대로(`tools/unity-export/maps.js` → `Resources/Data/maps.json`) — 오름길·내림길, 갈림길, 결진, 숨은 방.
  - 장단 발판(두 박 나타나고 두 박 사라짐, 반 박 앞서 깜빡임) · 무너지는 기와(밟으면 한 박 뒤 무너지고 네 박 뒤 돌아옴)
  - 바람(마디마다 방향이 바뀌고 마지막 박은 잔잔, 공중에서 더 밀림) · 결진(들어서면 문이 닫히고 다 베면 열림)
  - 금 간 바위(베거나 대시하면 무너짐) 뒤의 상자(숨 +1, 숨이 가득하면 천고 기운)
  - **출구 결계** + **뒤쫓는 적**(베지 않고 지나친 적이 먹을 타고 따라옴), 오른쪽 위에 "벤 적 k / n · 결계"
- **우두머리**: 넓어진 천고대(44칸)와 결계 위치, 결계 안에 묶이고 바위에 끼지 않게.
- **그림**: 양발 달리기(8프레임)·우두머리 걷기, 마당 소품·깃대·상자·문, 한지 패 HUD(관문 이름·기력/기세), 비급·오의 카드 아이콘,
  아이템 아이콘(`Sprites/it-*.png`), 앱 아이콘(`Assets/Cheongo/Icons/icon-512.png` — 프로젝트를 열면 자동으로 플레이어 아이콘으로 지정).
- 빠진 것: 연(갈고리)·금줄, 안개, 차오르는 먹(휘모리 오름길) — 이 셋이 든 관문은 내보내지 않습니다.

## 데이터·그림 다시 뽑기 (웹을 고친 뒤)
```
python3 -m http.server 8765 &        # 저장소 루트에서
node tools/unity-export/export.js --all
node tools/unity-export/maps.js
```

## 점수
`벤 적×10 + 간파×25 + 완벽 간파×40 + 넘은 관문×120(천고대 도달 300) + 우두머리 1000 + 남은 시간(초)×3`
등급: 甲 2000 이상 · 乙 1400 · 丙 700 · 丁 그 아래. 순위는 이 PC에만 날짜별로 남습니다.
수치는 `GameRoot.Booth.cs` 맨 위 `Booth` 상수에서 바꿉니다.

## 확인한 것 / 직접 봐야 할 것
- C# 전체를 Unity 없이 컴파일(Roslyn + UnityEngine 참조 어셈블리)해 오류 0, `Tests~`의 이동·지형 시험 통과(발판 박자·기와·금 간 바위).
- Unity에서 직접 확인이 필요한 것: 새 땅 그림(발판·기와·바위·상자·깃대·결진 문·출구 결계)의 위치·크기, 한지 패 HUD, 카드 아이콘 배치, 앱 아이콘(Editor 스크립트는 여기서 컴파일 검사를 못 했습니다).
